# Changelog

All notable changes are documented here.

## 0.1.0 — 2026-08-14

- Initial deliverable implementation.
- Direct PubMed, Europe PMC and Crossref adapters for journal/date-range reconstruction.
- Collection profiles with ISSN/name matching and article-type filters.
- Cross-source transitive identity deduplication.
- Self-contained HTML, canonical JSON, source receipts and SHA-256 manifest.
- Fail-closed edition validator.
- Optional commit-pinned EvidenceRadar source bridge with explicit prohibition on artifact inputs.
- Deterministic fixtures, tests, CI and manual live-build workflow.
