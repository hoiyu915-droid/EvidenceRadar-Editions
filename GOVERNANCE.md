# Governance

EvidenceRadar Editions is currently maintained by `hoiyu915-droid` as a small open-source reference implementation.

The maintainer has final responsibility for releases, source adapters, security boundaries, license mapping and contract changes. Ordinary changes are reviewed through pull requests. Security-sensitive changes, upstream-pin changes and delivery-contract changes require explicit maintainer review even when tests pass.

The project favors narrow, evidence-backed evolution over compatibility-breaking rewrites. A contract field may be added in a backward-compatible release; removal or semantic redefinition requires a documented migration and a major version change once the project reaches 1.0.

Project governance does not override third-party API terms, publisher rights or the licenses described in `NOTICE.md`.
