# Roadmap

## Near term

- Add tested collection profiles for additional journals.
- Add publisher／journal feed adapters where they improve pre-index coverage without weakening provenance.
- Expand parser coverage for source-specific seasonal, issue-only and ahead-of-print date forms.
- Add correction, retraction and version-family events without counting them as ordinary new articles.
- Add optional full-text access probes with separate access receipts.

## Later

- Weekly／monthly archive index builder across many collection profiles.
- Translation handoff that preserves canonical article identity and source binding.
- Version-of-record／preprint family reconciliation.
- Signed release bundles and immutable edition releases.
- GitHub Pages publication layer that never bypasses bundle validation.

No roadmap item changes the core rule: Editions queries sources directly and does not consume EvidenceRadar generated output.
